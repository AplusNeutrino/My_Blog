## 软件说明
Toyosatomimi’s headphone 是一款面向 Windows 的实时双语字幕工具，用于监听电脑特定窗口正在播放的声音，并自动生成外语原文字幕与简体中文翻译。字幕以透明悬浮歌词窗的形式显示在所有窗口上方，适合在观看视频、收听播客、上网课、开会议、打游戏或使用其他应用时进行实时听译。

它的核心目标是让用户在不打断当前工作的情况下，看懂系统音频中的外语内容。中文作为主字幕显示在上方，外语原文作为副字幕显示在下方。

## 主要功能
Toyosatomimi’s headphone 支持监听 Windows 系统音频输出，并生成实时字幕。用户可以选择监听全局系统声音，也可以选择监听某个特定窗口的声音，减少其他应用声音对识别结果的干扰。

软件支持用户手动选择源语言，以降低自动语言判断带来的负担。语音识别结果会先生成原文字幕，再通过翻译系统输出简体中文字幕。

翻译功能支持接入主流模型 API，包括 OpenAI-compatible 接口、Claude、Gemini 等。用户也可以配置 DeepSeek、OpenRouter、Groq、Mistral、Qwen、Kimi、硅基流动等兼容接口服务。软件支持保存 API 配置，避免每次启动后重复输入。

软件还提供可选 AI 翻译规则：遇到人名、模型名、不熟悉的专有名词时尽量保留原文，例如 Mike 不翻译成“麦克”，Claude 作为模型名时保留为 Claude。


## 使用方式
启动 Toyosatomimi's headphone.exe 后，软件会打开主设置窗口，并显示悬浮字幕窗口。

常见操作方式：

在设置窗口中选择源语言。

选择音频来源：全局系统音频或指定窗口音频。

配置翻译方式：本地翻译或模型 API。

播放英文播客、视频、会议声音或游戏语音。

字幕会自动显示在屏幕上方或用户设置的位置。

需要移动或调整字幕区域时，可以打开调整模式；日常使用时关闭调整模式，让字幕窗口保持透明、低干扰显示。


## 字幕外观与布局
软件支持高度自定义字幕样式。中文主字幕显示在上，外语原文显示在下，整体效果接近音乐歌词悬浮窗。
可调整项目包括：

字幕窗口位置、宽度、高度、行距、中文字距、原文字距、字体大小、字体颜色、描边颜色、描边粗细、透明度、底色、底色透明度等。

默认状态下字幕窗口为透明背景。开启调整模式后，会显示边框，方便拖动和缩放字幕区域。底色可以设置为只出现在文字后方，并随每句话出现和消失。

## 数据与配置
用户配置默认保存在本机。软件会保存字幕样式、窗口位置、语言设置、模型服务配置等内容。

API Key 不直接写入普通配置文件，而是通过 Windows 凭据管理器保存；配置文件只保存 provider、model、base_url 等非敏感信息。

## 运行依赖
支持环境：Windows 10 / Windows 11，推荐 Windows 11 x64。

发布包已打包为独立 Windows 程序，正常情况下不需要用户手动安装 Python 环境。首次运行时，如果系统安全策略或杀毒软件拦截，请允许程序访问音频设备和网络连接，否则可能影响音频监听或模型 API 翻译。
