## 软件说明

阿卡夏便笺 Akasha Notes 是一款高度自定义化的轻量级 Windows 桌面贴纸小组件工具，用于在桌面上显示透明文字板、计划表、清单和分类看板。桌面小组件负责低干扰展示内容，编辑器窗口负责文字输入、格式设置、网格调整和外观配置。

它适合用来放置每日计划、学习清单、项目进度、娱乐安排、备忘分区等需要长期停留在桌面的文字信息。

## 主要功能
阿卡夏便笺支持在桌面显示透明文字小组件。小组件可以锁定，锁定后不容易被误拖动、误点击，也不会强制置顶，其他窗口可以正常覆盖它，更接近桌面贴纸的使用体验。
编辑器支持常见富文本功能，包括：

加粗、斜体、下划线、删除线、
字号调整、
文字颜色、
高亮颜色、
项目符号列表、
编号列表、
左对齐、居中、右对齐、
分割线、
多格网格布局。

小组件支持单块文字和网格文字。网格模式下可以设置行数、列数、行高比例、列宽比例，也可以直接拖动单元格边界调整宽窄高低。软件还支持合并和拆分单元格，适合制作类似表格的一对多、多对一布局。

## 使用方式
启动 AkashaNotes.exe 后，软件会打开编辑器窗口，并在桌面显示对应的小组件。编辑器关闭后，程序仍会留在系统托盘后台运行。

常见操作方式：
在编辑器中点击某个单元格。
输入或粘贴文字内容。
使用顶部工具栏调整格式。
内容会自动同步到桌面小组件。

需要移动或缩放小组件时，先解锁；日常查看时保持锁定。
托盘图标支持打开编辑器、锁定/解锁所有小组件、导入导出备份、设置开机启动和退出程序。

## 外观与布局
软件支持调整桌面小组件的背景透明度、边框、圆角、内边距、默认字号和默认文字颜色。可以根据桌面壁纸和使用场景，把它调成接近“透明贴纸”“暗色看板”或“轻量计划表”的样式。
多显示器用户可以在设置面板中选择目标显示器，并快速把小组件移动到指定屏幕。

## 数据与备份

用户数据默认保存在本机：
%LOCALAPPDATA%\AkashaNotes\boards.json

软件支持通过托盘菜单导入和导出备份文件。

如果你之前使用过旧版本 Desktop Text Board，新版本会在首次运行时尝试从旧目录复制已有数据到 Akasha Notes 的新数据目录。

## 运行依赖

支持环境：
Windows 10 / Windows 11，推荐 Windows 11

需要 .NET 8 Windows Desktop Runtime

如果双击无法启动，通常需要先安装 .NET 8 Windows Desktop Runtime。
